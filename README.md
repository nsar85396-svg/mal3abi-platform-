# ملعبي | Mal3abi

منصة عربية لحجز الملاعب الرياضية — React + Vite + Supabase.

## المرحلة الأولى المنجزة
- واجهة عربية RTL متجاوبة مع الهاتف، بتصميم داكن وأخضر وخط Cairo.
- بطاقات أولية لـ20 ملعبًا: 10 خماسية و10 سداسية.
- فلترة حسب نوع الملعب والبحث بالاسم.
- نموذج حجز لمدة ساعة، والدفع في الملعب، واختيار موعد ضمن الأيام السبعة القادمة.
- مخطط قاعدة بيانات Supabase مع سياسات RLS.
- منع الحجز المتداخل على مستوى قاعدة البيانات بقيد exclusion، بما يحمي من الطلبات المتزامنة.
- حساب عمولة أولية 10% في قاعدة البيانات (تحتاج تأكيدًا قبل الإطلاق).
- فحص بناء تلقائي عبر GitHub Actions.

## تشغيل الواجهة

```bash
npm install
cp .env.example .env
npm run dev
```

أضف `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` إلى `.env` بعد إنشاء مشروع Supabase جديد.

## إعداد قاعدة البيانات
شغّل `supabase/schema.sql` في SQL Editor داخل مشروع Supabase جديد مستقل. **لا تستخدم قاعدة بيانات الموقع القديم.**

## قبل الإطلاق
- استبدال أسماء ومناطق وأسعار الملاعب التجريبية بالبيانات الصحيحة.
- تأكيد نسبة العمولة.
- إعداد تسجيل دخول الإدارة وتعيين مدير موثوق عبر Supabase Auth.
- بناء لوحة الإدارة وإدارة الإلغاء والتأكيد.
- إعداد WhatsApp Business Cloud API من خلال خدمة خادمية وأسرار آمنة، وليس من الواجهة.
- إضافة تحقق الهاتف ومكافحة إساءة الاستخدام.
- اختبار حجزين متزامنين واختبار شامل قبل النشر.

## تنبيه
من دون إعداد Supabase، تعمل الواجهة كمعاينة ولا تحفظ حجوزات فعلية. المشروع ليس جاهزًا للإنتاج بعد.
