# ملعبي | Mal3abi

منصة عربية لحجز الملاعب الرياضية.

## حالة المشروع
- مستودع جديد مستقل عن الموقع القديم.
- الواجهة المطلوبة: عربية بالكامل مع دعم RTL.
- التصميم: داكن رياضي، أخضر، وخط Cairo.
- الحجوزات: من 15:00 إلى 02:00، وحتى 7 أيام مقدمًا.
- الدفع: في الملعب.
- منع الحجز المزدوج يجب أن يُفرض على مستوى قاعدة البيانات.
- لوحة إدارة للملاعب والحجوزات والعملاء والعمولات.
- تكامل WhatsApp يُفعّل بعد إعداد مزود رسمي وحفظ بيانات الاعتماد كأسرار آمنة.

## ملاحظات أمان
لا تضع كلمات مرور أو مفاتيح API أو رموز إدارة ثابتة داخل المستودع.
لا تستخدم بيانات اعتماد أو قاعدة بيانات الموقع القديم.

## مراحل التنفيذ
1. إعداد هيكل التطبيق والواجهة العربية.
2. إعداد قاعدة البيانات والمصادقة والصلاحيات.
3. تنفيذ الحجوزات ومنع التعارض ذريًا.
4. بناء لوحة الإدارة وحساب العمولات.
5. ربط الإشعارات واختبار التدفق كاملًا.
